# История изменений

Новые версии сверху. Описание релиза на GitHub и changelog на CurseForge берутся из английской версии, [CHANGELOG.md](CHANGELOG.md).

## 1.0.2
- Новая серверная настройка `how_many_huge_heavy_items_overburdens` в `config/tfc_curios_weight-server.toml`: сколько огромных и очень тяжёлых предметов в инвентаре дают игроку перегруз (Overburdened). По умолчанию 2 — правило самой TFC. При 1 перегруз даёт и один такой предмет, а не только изнурение (Exhausted). Броня, надетая в свой слот, и щит во второй руке для неё не считаются переносимыми: они учитываются как раньше. Слоты Curios живут по своему правилу: один такой предмет в них по-прежнему бесплатен. Больше 2 поставить нельзя: сама TFC даёт перегруз от двух.
- По умолчанию всё как в 1.0.1. NeoForge отправляет настройку подключившимся клиентам, поэтому мод, который берёт это число на клиенте, следует тому же правилу. Та же настройка есть в 1.0.2 для Minecraft 1.20.1.

## 1.0.1
- Порт на Minecraft 1.21.1 и NeoForge. Расчёт веса работает так же, как в 1.0.0.
- Версия мода содержит версию Minecraft, и имя jar тоже: `tfc_curios_weight-1.0.1+1.21.1.jar`.

## 1.0.0
- Первый выпуск. Добавляет расчёт веса для всех слотов Curios.
- Есть опция конфига, отключающая мод.
- Особый случай: игрок не получает эффект TFC Exhausted, если размер HUGE и вес VERY_HEAVY имеет **не более одного** предмета в слотах Curios. Это позволяет носить в слоте Curios один тяжёлый рюкзак без дебаффа. Любые другие сочетания предметов HUGE + VERY_HEAVY приводят к дебаффам.
