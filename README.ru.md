# TFC Curios Weight

[English](README.md) · **Русский**

## О моде

Простой аддон к TFC, который распространяет расчёт веса из TFC на слоты Curios. Это та же логика, которую TFC применяет к инвентарю игрока, только для слотов Curios.

## Требования

- Minecraft 1.21.1 на NeoForge 21.1.0+ (собрано против 21.1.265)
- TerraFirmaCraft 4.2.0+ (собрано против 4.2.12)
- Curios API 9.5.0+ (собрано против 9.5.1+1.21.1)

## История изменений

### 1.0.1
- Порт на Minecraft 1.21.1 и NeoForge. Расчёт веса работает так же, как в 1.0.0.
- Версия мода содержит версию Minecraft, и имя jar тоже: `tfc_curios_weight-1.0.1+1.21.1.jar`.

### 1.0.0
- Первый выпуск. Добавляет расчёт веса для всех слотов Curios.
- Есть опция конфига, отключающая мод.
- Особый случай: игрок не получает эффект TFC Exhausted, если размер HUGE и вес VERY_HEAVY имеет **не более одного** предмета в слотах Curios. Это позволяет носить в слоте Curios один тяжёлый рюкзак без дебаффа. Любые другие сочетания предметов HUGE + VERY_HEAVY приводят к дебаффам.

## Лицензия

Мод распространяется под лицензией MIT. Это значит, что его можно включать в сборки модов, не спрашивая моего разрешения.

TFC, аддоном к которому является этот мод, распространяется под лицензией EUPL. При использовании частей этого мода учитывайте, что лицензия TFC может распространяться и на них. Её текст доступен на странице TFC.

Curios, от которого зависит этот мод, распространяется под LGPL. Текст лицензии доступен на странице Curios.
